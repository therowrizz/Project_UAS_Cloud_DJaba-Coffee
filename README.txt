### Penjelasan File

* `html/index.html`
  Berisi struktur utama dan seluruh konten website.

* `css/styles.css`
  Berisi pengaturan tampilan, layout, animasi, dan desain responsif.

* `js/script.js`
  Berisi fungsi navigasi, efek scroll, pembaruan tahun otomatis, dan interaksi formulir.

## Deployment GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder ini ke repository.
3. Buka *Settings > Pages*.
4. Pada bagian *Build and deployment, pilih **Deploy from a branch*.
5. Pilih branch main dan folder / (root).
6. Klik *Save* dan tunggu hingga URL publik tersedia.
